# TechBlog - Blog Site Refactor

Bootstrap-based refactoring project for the Blog Site Group Assessment.

## Pages
- `index.html` - Home
- `about.html` - About Us
- `contact.html` - Contact Us

## Features
- Bootstrap 5.3 CDN
- Responsive Bootstrap navbar
- Bootstrap 3-column grid
- Consistent colour scheme
- Responsive cards and typography
- Footer on every page
- Contact form with dismissible Bootstrap alert

## Run
Open `index.html` in a browser. Internet access is required for Bootstrap CDN and remote images.
